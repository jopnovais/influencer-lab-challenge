# Desafio Técnico — Frontend Developer

## Sobre o desafio

Este repositório contém o teste técnico para candidatos à vaga de **Desenvolvedor Frontend** na **Influencers Lab.ia**.

O objetivo é avaliar sua capacidade de transformar um design em uma interface funcional, organizada e com código de qualidade — do jeito que fazemos no dia a dia.

---

## O que você deve construir

Implemente o fluxo de **"Crie sua influencer"** seguindo fielmente o layout disponível no Figma abaixo.

**Figma:** [Acessar o layout](https://www.figma.com/design/v4fXb9QGCHPPozwdbKhCl3/Teste-de-conhecimento---30-03-2026?node-id=0-1&p=f&m=dev)

O fluxo é composto por **4 etapas navegáveis:**

1. **DNA Base** — Upload de imagem de referência, nome, gênero, faixa etária e etnia
2. **Estilo e Cabelo** — Cor dos olhos, cor e estilo do cabelo, tipo de corpo
3. **Pele e Detalhes** — Tom de pele e características faciais
4. **Resultado Final** — Resumo das escolhas feitas

---

## Requisitos técnicos

- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS** ou CSS Modules — sua escolha, justifique
- Responsivo para desktop (mobile é um diferencial)
- O projeto deve rodar localmente com os comandos abaixo sem nenhuma configuração extra

```bash
npm install
npm run dev
```

---

## O que vamos avaliar

- Fidelidade ao layout do Figma
- Organização e clareza do código
- Componentização — saber separar responsabilidades
- Uso correto de estado entre as etapas do fluxo
- Qualidade do commit history
- README do seu projeto explicando as decisões tomadas

---

## Diferenciais (não obrigatório)

- Animações de transição entre os steps
- Drag & drop funcional no upload de imagem
- Deploy publicado (Vercel, Netlify, etc.)
- Uso de boas práticas de acessibilidade (a11y)

---

## Como entregar

1. Faça um **fork** deste repositório
2. Desenvolva em cima do seu fork
3. Ao finalizar, **envie o link do seu repositório** para o número do whatsapp que te passou este teste
4. No README do seu projeto, descreva brevemente:
   - Como rodar o projeto
   - As decisões técnicas que tomou
   - O que faria diferente com mais tempo
